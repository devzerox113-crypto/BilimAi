# BilimAi 0.3

Kivy-приложение для Android: чат с Claude (API Anthropic) + учёба. APK собирается на GitHub.

## Сборка
1. Загрузите всё содержимое папки в репозиторий GitHub (вместе с `.github`; папка `server` в APK не попадает).
2. Actions -> `Build APK` -> дождитесь галочки (20-30 мин) -> Artifacts -> `BilimAi-apk`.
3. В приложении: Меню -> Настройки -> вставьте API-ключ (console.anthropic.com).

## Возможности
- Чаты с историей, поиск по чатам, переименование, экспорт (через «Поделиться»).
- Фото, PDF, текстовые файлы; голосовой ввод и озвучка; ответы по мере генерации; веб-поиск.
- Режимы: беседа, репетитор, домашка (по фото), переводчик, программист, викторина, свой промпт.
- Учёба: карточки из темы/текста/чата, повтор ошибок, прогресс, серия дней, слабые темы.
- Избранные ответы, «Обо мне» (память), уровень (школа/экзамен/вуз/взрослый), PIN-код.
- Тёмная/светлая тема, размер шрифта, 12 языков ответов, интерфейс на 9 языках
  (новые функции переведены на ru/kk/en/tr, на остальных пока английский).

## Свой сервер (чтобы ключ не лежал на телефоне)
`server/server.py` - прокси без зависимостей: токены для пользователей, лимит запросов в день,
потоковая передача. Запуск: `ANTHROPIC_API_KEY=... TOKENS=alice,bob python server/server.py`
(или `server/Dockerfile`). Нужен HTTPS (Render, Railway, Fly.io, VPS + Caddy).
В приложении: Настройки -> «Адрес сервера» = https://ваш-домен, а в поле ключа - токен пользователя.
Лимиты хранятся в памяти: после перезапуска сервера счётчик обнуляется.

## Google Play
`Release build` (Actions, запуск вручную) собирает подписанный AAB. Нужен keystore и 4 секрета (см. комментарий в
`.github/workflows/release.yml`). Этот workflow не проверен - смотрите лог первого запуска.

## Заметки
- Веб-поиск включается в консоли Anthropic. Китайский/японский/корейский используют системный шрифт Android;
  арабский и хинди Kivy не поддерживает.
- PIN только закрывает вход в приложение, данные на устройстве он не шифрует. Ключ хранится в приватной папке приложения.
- Иконки и фоны: `pip install pillow && python make_assets.py`.
